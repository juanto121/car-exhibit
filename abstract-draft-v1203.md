# CAR 2027 Educational Exhibit — Abstract Draft

**Title:** Gear Up Your LLM: The Radiologist's Reporting Toolbox – A Practical Guide to Prompting, Context Engineering, and Tool Integration
*(title still open: "harness" variant under consideration)*

## LEARNING OBJECTIVES

1. Differentiate strategies for customizing LLM-based applications in radiology reporting: prompting, context engineering, and tool use, and state what each adds.
2. Apply a stepwise framework that combines these strategies to common reporting scenarios.
3. Compare reports generated by LLM-based applications with and without this framework to identify differences in organization, completeness, and fidelity to supplied findings.

## BACKGROUND

Applications based on large language models (LLMs) are increasingly used in radiology reporting to structure findings, draft impressions, and simplify reports. If used generically, they can omit findings, fabricate content, and produce inconsistent report formats. Output quality depends largely on how the model is guided, yet existing guidance is abundant, jargon-heavy, and often overwhelming for practicing radiologists. This educational exhibit presents a stepwise framework for customizing LLM-based applications in everyday reporting. The framework combines three strategies: prompting, which specifies the model's role, task, and output format; context engineering, which supplies templates, guideline criteria (e.g., Fleischner, O-RADS), reporting preferences, and reference documents retrieved on demand (retrieval-augmented generation, RAG); and tool use, which lets the model call external functions, such as calculators, through local Model Context Protocol (MCP) servers that keep data on-premises. The framework is applied to common reporting scenarios (e.g., incidental pulmonary nodules, adnexal lesions, incidental adrenal lesions). Side-by-side reports generated from identical findings, with and without the framework, illustrate differences in organization (required sections, in order), completeness (no omitted findings or descriptors), and fidelity to supplied findings (no fabricated or altered content).

## CONCLUSION

This stepwise framework translates technical LLM guidance into a practical approach that radiologists can adapt to everyday reporting. By combining these strategies, radiologists can use LLM-based applications to produce more organized, complete draft reports that remain faithful to supplied findings, while maintaining essential clinical oversight. As AI capabilities evolve, the ability to guide, contextualize, and critically review LLM outputs will be an increasingly valuable skill for radiologists incorporating these applications into clinical practice.
